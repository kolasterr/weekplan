# WeekPlan — планировщик недели работающего студента

Веб-приложение для планирования учебной недели студента, который совмещает учёбу с работой.
Помогает распределять задачи по свободным окнам в расписании, учитывать дедлайны и буферы,
планировать сессии подготовки к парам и тестам.

> **Демо-режим.** Приложение работает на localStorage браузера и не требует сервера.
> Расписание вуза, материалы для тестов и подписки на календарь — демонстрационные данные.
> Все введённые пользователем данные хранятся локально в браузере.

---

## Возможности

### 8 вкладок

1. **Моя неделя** — обзор плана на неделю, задачи по дням, статусы.
2. **Расписание вуза** — расписание пар по номеру группы (демо-данные), переключение недель,
   редактирование/отмена отдельной пары.
3. **Фиксированные события** — личные события с повторением по дням недели и шаблонами.
4. **Доступное время** — свободные окна, в которые можно ставить задачи.
5. **Учебные задачи** — задачи с дедлайнами, трудоёмкостью, приоритетом, дроблением на сессии.
6. **Результат планирования** — итоговый план недели с проверкой конфликтов и буферов.
7. **Материалы для подготовки** — дисциплины, тесты 3 типов, результаты и статистика,
   создание задач из тестов.
8. **Календарь и экспорт** — выгрузка плана в `.ics` (iCalendar), подписка на демо-календарь.

### Алгоритм планирования

- Учитывает университетские пары (фиксированные) и личные события.
- Дробит большие задачи на сессии по 30–90 минут с учётом буфера и дедлайна.
- Проверяет конфликты по времени и не ставит задачи в занятые слоты.
- 4 статуса: «Запланировано», «В процессе», «Выполнено», «Просрочено» (автоопределение).
- Кнопка «Перепланировать неделю» пересобирает план с учётом изменений.
- Ручная корректировка: изменение порядка, закрепление задачи за временем.

### Хранение данных

- Все данные в `localStorage` браузера под ключом `studentPlanner`.
- Автоматическая миграция при изменении структуры (версия схемы хранится в данных).
- Кнопка «Загрузить пример» заполняет неделю демо-данными.
- Кнопка «Очистить неделю» сбрасывает данные.

## Как опубликовать на GitHub Pages

### Шаг 1. Создайте репозиторий на GitHub

1. Зайдите на https://github.com/new.
2. **Repository name:** `weekplan` (или любое другое).
3. **Visibility:** `Public` (для бесплатного GitHub Pages).
4. **НЕ** ставьте галочки «Add a README», «.gitignore», «license» — оставьте репозиторий пустым.
5. Нажмите **Create repository**.

### Шаг 2. Загрузите файлы

В только что созданном пустом репозитории:

1. Нажмите **Add file → Upload files**.
2. Перетащите в зону загрузки два файла из папки `weekplan-github/`:
   - `index.html` — само приложение;
   - `.nojekyll` — пустой файл, отключает обработку Jekyll (нужен, чтобы GitHub Pages
     отдавал файл «как есть», без изменений).
3. Внизу введите commit message, например `Initial commit: WeekPlan app`.
4. Нажмите **Commit changes**.

> Файл `.nojekyll` скрытый (начинается с точки). В macOS Finder включите отображение
> скрытых файлов комбинацией `Cmd + Shift + .`. В Windows Explorer — вкладка
> «Вид → Скрытые элементы».

### Шаг 3. Включите GitHub Pages

1. В репозитории откройте вкладку **Settings** (не путать с настройками профиля).
2. В левом меню найдите раздел **Pages** (под `Code and automation`).
3. В блоке **Build and deployment**:
   - **Source:** `Deploy from a branch`;
   - **Branch:** `main` / `(root)` → нажмите **Save**.
4. Вверху страницы появится надпись:

   ```
   Your site is live at https://<ваш-логин>.github.io/weekplan/
   ```

   Ссылка активируется через 1–2 минуты после первого деплоя.

### Шаг 4. Откройте сайт

Перейдите по ссылке — приложение загрузится сразу.

```
https://<ваш-логин>.github.io/weekplan/
```

## Как обновлять сайт после изменений

Каждое изменение файла `index.html` в репозитории автоматически запускает пересборку
GitHub Pages. Деплой занимает 1–2 минуты.

### Через веб-интерфейс GitHub

1. Откройте репозиторий → файл `index.html`.
2. Нажмите карандаш (Edit) в правом верхнем углу.
3. Можно загрузить новую версию через **Upload files** (Step 2 выше), заменив старую.

### Через Git в терминале (если установлено)

```bash
git clone https://github.com/<ваш-логин>/weekplan.git
cd weekplan
# скопируйте новый index.html поверх старого
git add index.html
git commit -m "Update planner"
git push origin main
```

## Как запустить локально

Файл `index.html` можно открыть двойным щелчком — приложение работает без сервера.
Чтобы данные сохранялись между сессиями, не открывайте файл в режиме инкогнито.

Для локальной разработки удобно поднять простой HTTP-сервер:

```bash
# Python 3
python3 -m http.server 8000

# затем откройте http://localhost:8000/
```
